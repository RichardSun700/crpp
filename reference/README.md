# CRPP reference flow

This directory contains the minimal Node.js reference router and CLI for the synthetic employee-exit example.

- `router.mjs` deterministically separates company facts, portable capability, joint context, and audit evidence.
- `cli.mjs` reads a synthetic JSON fixture and prints the routed output.

This code is explanatory and testable. It is not a production identity service, policy engine, de-identification system, escrow service, or legal-compliance product.
