# Synthetic employee-exit demo

This fixture represents the moment a contributor leaves a project. It is entirely invented.

The same authorized work event produces:

- a company record containing the complete synthetic business facts;
- one capability-only Portable Projection for each contributor;
- a Joint Context Escrow record for inseparable collaboration; and
- three commitment-linked audit events.

Run it from the repository root with `npm run demo`. The restricted markers are deliberately present in the company record and absent from every portable projection.
