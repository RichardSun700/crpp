# CRPP 0.1.0-draft.1 Validation

Status: pre-publication candidate

## Included

- bilingual top-level explanation;
- English normative draft and complete Chinese translation;
- 33 aligned normative rule references;
- eight public CRPP object schemas plus shared definitions;
- valid and invalid structural fixtures;
- nine fairness decision scenarios;
- five end-to-end synthetic examples;
- deterministic conformance runner;
- governance, contribution, security, threat-model, and CEP documents.

## Required release gates

- `npm ci --ignore-scripts`
- `npm run lint`
- `npm test`
- `npm run test:coverage`
- `npm run validate`
- `npm audit --audit-level=moderate`
- `git diff --check`
- clean clone verification
- GitHub Actions passing on the public default branch

## Boundaries

This draft does not certify legal compliance, anonymization, enterprise security, or production readiness. It contains no real context data. Reference projection, escrow, signature, identity, MCP, and REST implementations remain future milestones.
